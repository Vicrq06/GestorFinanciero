Este proyecto tiene como fin llevar un sistema de registro de gastos mensual (tanto fijos como variables), alertas de gastos, porcentajes de ahorro con respecto a dinero libre, dinero que se puede gastar y estrategias para gastos fijos y uso de pagos a una cuota en creditos.
Aqui estaremos implementando normalizacion de datos, analisis univariado, visualizacion y ademas POO.

debe tener separacion por mese para comparativa de gastos, ademas de un sistema de calculo de interes para saber si es viable una compra a cuotas o no
